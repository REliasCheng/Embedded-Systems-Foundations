# 调试与验证

## 电路仿真

CircuitJS 用于观察节点电压、电流方向和波形。验证时一次只改变一个开关或器件值，并记录输入条件、关键节点和输出。NE555 应同时观察电容电压和输出方波，不能只听蜂鸣器是否发声。

## 数字逻辑

Digital 工程从子电路向上验证：

1. 逻辑门真值表；
2. 半加器和全加器的所有输入组合；
3. 8 位加法的普通进位、连续进位和最高位溢出；
4. 寄存器 WE/OE；
5. 总线是否出现冲突或高阻态；
6. CPU 逐拍数据流和内存写回。

主工程依赖同目录的自定义 `.dig` 文件，移动时必须保持文件名和相对关系。

## STC8 控制程序

源资料使用天问图形化环境和 24 MHz 时钟配置。下载前应确认：

- 当前连接设备的实际 COM 口；
- 芯片型号和下载频率；
- 程序对应的引脚与控制板原理图一致；
- 负载是否需要三极管/MOS 驱动；
- UART 波特率、TX/RX 方向和共地。

LED、PWM 和蜂鸣器可用示波器或逻辑分析仪测量频率、占空比和电平。UART 项目应先抓取命令帧，再连接语音模块。不要把“成功生成程序”当作硬件验证。
