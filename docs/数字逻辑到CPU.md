# 数字逻辑到 CPU

## 1. 从真值表到算术

与、或、非、异或门把输入组合映射为输出。半加器用 XOR 产生和位、AND 产生进位；全加器加入低位进位；8 位加法器把全加器级联。这个过程说明多位算术来自相同小单元的组合，而进位连接决定结果是否正确。

## 2. 从组合逻辑到状态

组合电路不会记住过去。锁存器引入反馈，寄存器把多个 1 bit 存储单元组合，并用 WE 决定何时采样输入、用 OE 决定何时驱动总线。高阻态让多个模块共享总线，但任意时刻只能有一个有效输出源。

## 3. 从寄存器到内存

内存控制单元使用地址选择具体存储位置。简化模型使用 4 位地址访问 16 个位置，8 位数据总线传输指令或数据。MAR 保存地址，MBR 保存从内存读取或准备写入的字。

## 4. 从数据通路到指令

IR 中高 4 位作为操作码，低 4 位作为地址。示例 ISA 只包含 `LOAD_A`、`LOAD_B`、`ADD` 和 `STORE`，足以演示指令如何变成寄存器和内存之间的数据移动。

```text
Fetch:   PC → MAR → Memory → MBR → IR
Decode:  IR opcode → control sequence
Execute: Memory/Register/ALU → destination
```

## 5. 从手动控制到自动运行

手动 CPU 用开关直接控制各模块 WE/OE，适合确认单步数据路径。自动版本加入 Clock、步骤计数器和 LookUpTable。操作码与步骤号共同选择 17 位控制字，每一位连接一个控制信号，使取指和执行按固定节拍重复。

该 CPU 是面向数据通路观察的简化架构，指令集包含 `LOAD_A`、`LOAD_B`、`ADD` 和 `STORE`。取指、解码与执行过程可以直接映射到总线、寄存器和控制线。
