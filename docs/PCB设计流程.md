# PCB 设计流程

## 需求与接口

先定义供电、电流预算、输入输出、连接器、板框和机械位置。旅游解说仪需要明确 STC8 与 CH7800 的 UART、电源、按键和扬声器链路；NE555 电子琴需要明确供电、频率选择按键、RC 网络和蜂鸣器。

## 器件选型与 BOM

选型同时考虑电气参数、封装、可采购性和装配方式。BOM 至少要核对：

- 位号、数量与器件值；
- 封装和引脚数；
- 供应商编号；
- 极性、额定电压和功率；
- 接口、按键等机械尺寸。

## 原理图

原理图阶段先连接电源和地，再处理主芯片、时钟/复位、通信、输入和负载。检查电源引脚、去耦、上拉/下拉、TX/RX 方向以及端口复用。网络标签只能减少画线，不能替代对连接关系的检查。

## PCB 布局与布线

1. 确定板框和安装孔。
2. 优先摆放接口、按键和机械约束器件。
3. 将去耦电容靠近芯片电源引脚。
4. 缩短大电流、高频和敏感模拟回路。
5. 根据电流与制造规则设置线宽、间距和过孔。
6. 铺设地平面并检查回流路径。

## 检查与制造

ERC/DRC 应检查未连接网络、短路、间距、线宽、过孔和板框。生产前还应检查 Gerber、钻孔、丝印、阻焊和器件方向。焊接后先断电测量短路，再限流上电并分模块验证。

现有仓库有原理图、参考线路和 BOM，但没有原生 PCB、DRC 或 Gerber，因此这些后半流程是明确的补充方向，而不是已经完成的制造记录。
