# 电子电路基础

这一部分保存从直流回路到有源器件控制的 CircuitJS 实践。内容不是器件名词列表，而是沿着“电源如何形成电流、负载如何分配电压与电流、控制端如何改变输出”的问题组织。

## 电路作用

嵌入式系统最终通过电压和电流与真实世界交互。GPIO 的高低电平、供电压降、LED 限流、继电器与电机驱动，都需要先理解闭合回路和器件工作区。仓库因此保留了可重新导入仿真器的电路，而不是只保存讲义截图。

## 仿真文件

```text
电源 → 串并联与欧姆定律 → LED/整流
                         ↓
控制信号 → 三极管/MOS/继电器 → 负载
                         ↓
模拟比较 → 双稳态触发 → 数字状态
```

## 电气行为

串并联练习把计算和实际节点连接起来：串联支路电流相同，并联支路电压相同；混合网络先等效化简，再回到支路求值。三极管和 MOS 电路进一步建立“控制端与功率通路分离”的认识，这直接对应后续 MCU 无法直接驱动大电流负载时的外部驱动方案。

比较器把连续电压转换为离散状态，双稳态电路则能保存状态。它们连接了模拟电路与数字逻辑：逻辑 0/1 不是抽象符号，而是有电压范围、转换条件和稳定性的物理信号。

## 常见问题

- 区分传统电流方向和电子运动方向，同时保持电路计算约定一致。
- 在三极管、MOS 和继电器中识别控制回路与负载回路。
- 认识开路、短路和悬空输入对电路状态的不同影响。
- 从比较器阈值和反馈理解双稳态电路为什么能保存 1 bit 状态。
