# 原理图与 PCB 设计

这一部分记录从需求、器件和连接关系进入原理图与 PCB 的基本工作流。现有资产包括 STC8 控制板原理图、旅游解说仪参考线路，以及两个综合项目中的 BOM。源资料没有原生 PCB 布局、Gerber 和 DRC 报告，因此仓库重点展示可确认的设计输入与分析方法。

## 文件范围

嵌入式程序只能在正确的硬件接口上工作。电源、去耦、连接器、晶振、下载接口和外设引脚一旦定义错误，软件调试无法弥补。原理图负责表达电气连接，PCB 负责把连接转化为可制造的铜箔、焊盘和机械布局。

## 设计流程

```text
需求 → 器件选型 → 原理图 → 网络检查 → PCB 布局 → PCB 布线
     → DRC → BOM / Gerber → 打样 → 焊接 → 上电检查
```

现有文件覆盖 BOM、原理图和布局布线方法分析；不包含 DRC、Gerber、打样或焊接记录。

## 原理图检查

### 器件与供电

BOM 不能只看器件名称，还要检查封装、引脚数、供应商编号和数量。电源入口附近需要考虑极性、额定电压和去耦；芯片附近的 100 nF 电容承担高频旁路，较大的电容用于较低频的电源波动。

### 原理图网络

原理图检查关注电源与地、接口方向、上拉/下拉、下载与串口复用、负载驱动能力。旅游解说仪中 MCU UART 与 CH7800 的收发方向必须交叉对应；按键输入需要稳定默认电平。

### PCB 布局与布线

布局先处理板框、接口、按键和机械位置，再安排芯片与去耦。电源和大电流回路应缩短、加宽；敏感信号远离高频或大电流开关节点。走线完成后需要 DRC 检查间距、线宽、未连接网络和过孔规则。

## 设计约束

- 从原理图确认信号方向，而不是根据接口名称猜测 TX/RX。
- 同时满足电气连接、机械位置和可焊接性。
- 区分参考图/BOM 与可生产 PCB 工程。
- 将软件使用的端口映射回原理图，排查复用冲突和驱动能力。

## 检查项

现有文件适合进行网络追踪、器件核对和软件端口映射。完整 PCB 验证还需要原生 EDA 工程执行 ERC/DRC，导出 Gerber 后进行制造检查，并在实物上完成短路、供电和接口测试。

## 与固件的连接

PCB 流程把“代码控制某个引脚”扩展为“引脚经过怎样的电路驱动什么负载”。这使调试能够在软件、接口、电源和负载四个层面定位，而不是把所有异常都归因于程序。
