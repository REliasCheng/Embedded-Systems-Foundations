# 旅游解说仪控制实践

这个项目使用 STC8 控制板连接 CH7800 语音模块，通过按键发送上一曲、下一曲、播放和暂停命令。现有资产覆盖 UART 图形化程序、模块接口图、应用参考线路和器件 BOM。

## STC8 与 CH7800

语音播放由专用模块负责，MCU 不直接解码音频，而是通过串口发送控制帧。这种分工把人机输入、通信协议和功率输出拆开，符合嵌入式系统常见的模块协作方式。

## 系统结构

```text
按键 P5.1-P5.4 ──> STC8 应用逻辑
                         │
                    UART1 9600
                  P3.0 RX / P3.1 TX
                         │
                       CH7800
                         │
                    音频存储 / 功放 / 喇叭
```

## 控制帧

- [旅游讲解仪驱动](course/twen-blocks/旅游讲解仪驱动.hd)初始化 24 MHz 时钟、P3.0/P3.1 UART1、P3.2 输入和四组 7 字节命令数组。
- [音乐播放控制](course/twen-blocks/音乐播放控制.hd)使用 P5.1-P5.4 四个按键分别发送上一曲、下一曲、播放和暂停命令。
- [UART 接口图](assets/串口与语音模块接口.png)说明 STC8 与语音模块的串口连接。
- [BOM](course/bom/旅游解说仪BOM.xlsx)包含 CH7800、连接器、排针、100 nF 去耦电容和四个按键。

命令以 `0x7E` 开头、`0xEF` 结束，中间字段区分控制类型；程序通过 `uart_putbuff` 一次发送 7 字节。按键输入取反后触发命令，说明硬件采用低电平有效的输入逻辑。

## UART 与功率路径

UART 两端的 TX/RX 需要交叉连接并共地。P3.0/P3.1 在程序中被配置为 UART1 接收/发送，引脚复用必须与控制板原理图一致。100 nF 电容应靠近模块电源引脚，按键则需要稳定的默认电平和必要的消抖。

[应用线路参考图](assets/应用线路参考图.jpg)、[CH7800 引脚图](assets/CH7800芯片引脚图.jpg)和[配置说明](assets/CH7800配置文件解释.jpg)用于追踪这些连接。

## 接口约束

- 核对 UART 电平、波特率、TX/RX 方向和共地。
- 让命令帧长度、起止字节和功能码保持一致。
- 处理按键低电平有效和重复触发，避免一次按下连续发送多帧。
- 区分 MCU 控制逻辑、音频模块播放能力和扬声器功率路径。

## 检查项

复现时先用串口工具或逻辑分析仪确认 9600 波特率与 7 字节帧，再连接 CH7800 验证四个控制命令。若模块无响应，应依次检查供电、共地、串口方向、模块音频文件和命令内容。当前仓库提供接口图、程序和验证步骤，串口抓包与现场视频待实机测试时补充。

## 模块边界

按键由 MCU 读取，UART 帧交给 CH7800，音频解码与播放留在专用芯片；BOM 和线路图记录两部分的接口。
