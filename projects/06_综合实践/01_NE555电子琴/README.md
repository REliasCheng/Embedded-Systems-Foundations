# NE555 电子琴设计实践

这个项目使用 NE555 无稳态振荡电路产生方波，通过按键选择不同电阻支路改变充放电时间，从而得到不同频率并驱动蜂鸣器发声。仓库保留功能框图仿真、关键状态图和器件 BOM。

## 振荡器

声音的音高由振动频率决定。NE555 内部的阈值比较、触发比较、RS 锁存和放电晶体管，可以让外部电容在两个阈值之间反复充放电，把模拟电压变化转换成周期数字信号。

## 电路

```text
VCC
 │
Ra / 按键选择的 Rb
 │
C1 充放电节点 ──> NE555 阈值与触发比较器
                         ↓
                    锁存 / 放电管
                         ↓
                    方波输出 → 蜂鸣器
```

## 充放电过程

电容充电时，输出保持高电平；节点电压超过上阈值后，锁存状态翻转，放电晶体管导通，电容经电阻放电，输出变低。电压降到下阈值后再次翻转，循环形成方波。

改变电阻支路会改变 RC 时间常数，因此改变振荡周期和音高。BOM 中设置多组阻值和按键，正是把不同频率离散为多个音符选择。频率、周期和占空比的关系见[概念图](assets/频率&周期&占空比概念.png)。

## 器件约束

- 同时分析 NE555 内部比较/锁存状态与外部 RC 电流路径。
- 让每个按键选择明确阻值，避免多个支路并联导致频率偏移。
- 处理蜂鸣器类型、驱动能力、供电和电容极性。
- 将理论 RC 参数与真实器件公差、蜂鸣器响应范围区分开。

## 仿真

可在 CircuitJS 中观察电容节点和输出波形，验证高低阈值、周期和占空比随阻值变化。PCB 与实物阶段还应测量各按键对应频率，并检查供电纹波与蜂鸣器响度。当前资产不包含实测频率表和焊接照片。

## 频率控制

该项目把电阻、电容、三极管、比较器和锁存器组合为可感知输出，说明模拟电路可以直接产生数字时序，也为 MCU 中定时器/PWM 的频率控制建立硬件对照。
