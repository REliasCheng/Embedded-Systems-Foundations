# 数字逻辑与组合电路

这一组 Digital 工程从基本逻辑门逐层构建半加器、全加器和 8 位加法链，并保留一个加法通路 ALU 原型及相同与门功能的 Digital、Verilog、VHDL 三种表达。

## 从真值表到算术

数字逻辑把电路中的稳定高低电平解释为 0 和 1。组合电路的输出只取决于当前输入，因此可以用真值表、布尔表达式和门级连接互相验证。加法器是从门电路走向 CPU 数据通路的关键中间层。

## 逻辑链路

```text
AND / OR / NOT / XOR
          ↓
       半加器
          ↓  加入低位进位
       全加器
          ↓  级联进位
      8 位加法器
          ↓
     ALU 加法通路
```

## Digital 工程

- [半加器.dig](course/digital/半加器.dig)：`SUM = A XOR B`，`Carry = A AND B`。
- [全加器.dig](course/digital/全加器.dig)：两个半加器处理输入与进位，再用 OR 合并两个进位来源。
- [8位加法器(合并).dig](course/digital/8位加法器%28合并%29.dig)：将各位全加器串联，前一级 Carry 进入后一级。
- [ALU.dig](course/digital/ALU.dig)：包含 8 位加法器、常量和三态驱动，用输出使能控制结果是否进入总线。
- [and_logic.dig](course/digital/and_logic.dig)、[Verilog](course/digital/and_logic.v)、[VHDL](course/digital/and_logic.vhdl)：同一与逻辑的图形化与 HDL 表达对照。

## HDL 与电路

半加器不能接收低位进位，全加器新增 `Cin` 后才能用于多位运算。8 位工程采用逐级进位结构，逻辑清晰，但最高位必须等待前面各级 Carry 传播；这解释了位宽扩大后组合路径变长的问题。

ALU 文件当前实现**加法通路原型**，运算范围为多位加法与结果输出控制。三态 Driver 在 OE 未使能时退出共享总线，避免两个输出同时驱动总线。替换自定义异或门时出现过高阻态现象，因此验证时需要检查输入驱动和子电路端口。

## 进位与总线约束

- 区分“结果位”和“进位位”，并把 Carry 连接到下一位。
- 识别逐级进位的传播延迟，而不是只验证单组输入。
- 正确处理三态、高阻态和总线竞争。
- 保持自定义 `.dig` 子电路与主工程位于可解析的相对路径。

## 验证

在 Digital v0.30 中依次打开门电路、半加器、全加器和 8 位加法器，遍历关键输入组合，检查 SUM/Carry。ALU 原型还要分别验证 OE 开启和关闭时的输出状态。HDL 文件用于对照接口表达；当前验证在 Digital 仿真环境完成。

## 与 CPU 数据通路的连接

这一链路说明 CPU 算术不是软件抽象，而是由门电路构成的组合网络。进位传播、三态控制和接口位宽会直接影响后续[CPU 数据通路](../03_计算机组成与CPU/README.md)的正确性。
